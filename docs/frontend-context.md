# Frontend Context (DayAnchor)

## Base
- Base URL: http://localhost:8080
- No auth in current backend; every request carries userId as query param or JSON field.

## Date and time formats
- LocalDate: "YYYY-MM-DD"
- LocalDateTime: ISO-8601 without timezone (example: "2026-02-14T10:30:00")
- All time is server-local time.

## Error format (only for IllegalArgumentException)
- HTTP 400
- JSON: { "timestamp": "date-time", "status": 400, "message": "..." }
- Other RuntimeException paths currently return 500 with default Spring error payload.

## Behavior notes
- Task creation requires title, taskDate, energyLevel, userId; status is set to PENDING by backend.
- Task list returns only PENDING tasks for the user.
- Daily templates list returns only active templates for the user.
- Daily task logs are generated by a scheduler every minute from active templates.
- Daily plan returns:
  - dailyLogs for the specified date
  - pendingTasks = all PENDING tasks for the user (not filtered by date)
- Completed count = completed daily logs + completed tasks for the date.
- Chest open:
  - Requires at least 1 enabled reward item and a chest rule.
  - Only one open per day per user.
  - Requires completed count >= rule.requiredCompletedCount.
  - Returns OpenChestResponse with opened=false and a message for failure cases.
- Work timer:
  - One record per user per date.
  - start and pause are idempotent.
  - totalSeconds includes running time when running=true.

## Data enums

- TaskStatus: PENDING | COMPLETED
